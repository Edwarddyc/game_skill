# Game 3 素材定制生成方案

## 拆分结论

采用三个 Skill：

1. `game3-terrain-tiles`：地形、悬崖、水面、浪花、阴影与地形配色变体。
2. `game3-buildings`：64/128 px 的俯视像素建筑、建筑系列与升级形态。
3. `game3-map-props-fx`：道路、岩石、树木、车辆及天气特效，并负责把不一致的参考素材归一到项目像素体系。

## 为什么这样拆

- Tileset 的核心约束是 64 px 网格、边角拓扑、无缝拼接与动画帧一致性。
- Buildings 的核心约束是单体轮廓、锚点、功能辨识度及多尺寸缩放策略。
- unclassified 不是统一风格：道路和岩石接近目标像素风，树、车辆、雨更像高分辨率概念素材。第三个 Skill 因此不能照抄来源，而要按资产类别路由并执行风格归一化。

## 统一生产基线

- 逻辑网格固定为 64 px；更大素材使用 64 的整数倍画布。
- 最终游戏素材使用透明 PNG，像素版本采用最近邻缩放。
- 统一俯视/正交视角、左上方光源、深色轮廓、有限色板和紧凑像素块。
- 生成时一张图只承担一个语义资产或一个同类图集，避免混合海报式输出。
- 原始素材只作为视觉参考；所有输出采用版本化文件名，默认不覆盖。

## 建议的调用参数

- 地形：生物群落、悬崖材质、所需边/角/内角、是否含水岸、色板、图集布局。
- 建筑：功能、阵营、占地、屋顶/墙体材质、升级等级、目标尺寸。
- 物件特效：模式、物件类型、逻辑占地、锚点、道路宽度或动画/平铺要求。

## 推荐的下一轮验证

分别用三个 Skill 生成一份最小样例：草地到沙地过渡图集、一座 64 px 铁匠铺、一个 64 px 树木或道路转角。以 1x 游戏显示效果验收后，再批量扩展主题和变体。
